# Context Admission Gate Example Python

This example demonstrates the concept of a 'Context Admission Gate' for AI models. It simulates filtering a collection of documents based on their relevance to a given user query, ensuring only pertinent information is passed into an AI model's limited context window. The script uses a simple keyword matching mechanism to decide which documents are 'admitted' or 'rejected'.

## Language

`python`

## How to Run

Save the code as `main.py`. Run it from your terminal using `python main.py`.
